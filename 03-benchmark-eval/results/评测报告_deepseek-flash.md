# 高中数学 Benchmark 全量评测报告 · deepseek-flash（DeepSeek-V4.1-Flash-1017）

> 评测对象：**deepseek-flash（DeepSeek-V4.1-Flash-1017）**（OpenAI 兼容端点 https://api.deepseek.com）  
> 数据集：`dataset/benchmark_v3.template.jsonl`，共 **4000** 题（6 板块 × 基础/中档/压轴）  
> 判分链路：交付包 `eval/evaluate.py`（`normalize_item` → `run_one`）+ `eval/metrics.py`（`summarize`）  
> 评测方式：`--mode normal`（常规作答，每题 1 次调用）；`--mode deep`（首答 + VERIFY 复核，每题 2.0 次调用，判分取末轮）  

> 口径说明：普通模式关闭 thinking（temperature=0，max_tokens=2048）；深度思考模式开启 thinking（reasoning_effort=high）+ 一轮独立复核，max_tokens=4096

## 七、结论

1. 全量 4000 题常规成绩 **90.52%（全量口径）/ 93.04%（有效作答口径）**；深度思考模式 91.80% / 95.53%。
2. 最弱板块（有效作答口径）：立体几何 83.24%、函数 94.35%。
3. 难度梯度（有效作答口径）：基础 95.14% → 中档 91.96% → 压轴 90.84%。
4. 无效作答 108 条（2.70%），分子分母口径见第一节，横向对比时须先对齐。

## 八、说明

- 指标全部由 `results_*.jsonl` 现算；`summary_*.md/json` 为交付包 `metrics` 的原样输出，可与本报告交叉核对。
- 逐题明细见 `per_item_*.csv`（`pred / correct / stage_answers / latency / error`），可按 id 抽查。
- deep 与 normal 的差异来自复核轮真实改判，改判条数与净收益已在第一节列出，可逐题对照 `stage_answers`。
- 截断与无效：normal 输出被 max_tokens 截断 119 题、未产出可抽取答案 108 题；deep 截断 356 题、未产出答案 156 题（思考链更长，更易触顶，故 deep 无效率略高于 normal）。
- 调用失败（HTTP 错误）：normal 0 条、deep 0 条；失败题已计入无效，不当作答错处理。
- 数据集含少量缺图题，无法作答，计入无效；两个模式口径一致，不影响横向比较。
