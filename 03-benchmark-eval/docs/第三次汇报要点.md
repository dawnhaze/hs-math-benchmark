## 第 2 页 · 为什么这版要重做采样

第二次汇报的数据有两个硬伤：

1. **板块失衡**：函数 639 条占 46%，导数只有 30 条；
2. **顺序爬的偏斜**：从第 239 页顺序续爬到 625 页，相邻页内容高度同质——
   实测导数类只占 **1.9%**；而在 26 万页里随机抽 30 页，导数类占 **8.3%**。

结论：**页码相邻 ≠ 内容相邻**。顺序爬适合"不漏页"，不适合"拉平板块"。
于是这版加了一条随机页采样的路线，专门补小板块。

| 路线 | 做法 | 本次产出 |
|---|---|---|
| 顺序页 | `/gzsx/shiti_page_N`，断点续爬 | 6,022 条 |
| **随机页** | 在 1,000–266,000 页间跳采，2,300 余页 | **33,666 条** |
| 菁优试卷 | sitemap → 试卷页 → 题目页 | 687 条 |

## 第 5 页 · 板块构成：五个主板块完全均衡，导数单列

要求：各类型题量差 ≤100，同时保住 4,000 条。做法分两步。

**第一步，五个主板块 maximin 均分**：每个板块 740 条，极差 **0**。
（水位法：先把储量最小的板块装满，剩余名额均分。）

| 板块 | 题量 | 基础 | 中档 | 压轴 |
|---|---|---|---|---|
| 函数 | 740 | 296 | 296 | 148 |
| 数列 | 740 | 296 | 296 | 148 |
| 立体几何 | 740 | 296 | 296 | 148 |
| 解析几何 | 740 | 296 | 296 | 148 |
| 概率与统计 | 740 | 296 | 296 | 148 |
| **导数及其应用** | **300** | 120 | 120 | 60 |
| **合计** | **4,000** | 1,600 | 1,600 | 800 |

**第二步，导数单独设配额 300。**
四选一导数题的供给有限：随机页里含导数关键词的题 287 道，其中 216 道是填空/解答（没有四个选项）。
本次可判分的导数池一共 614 道，取 300 条单列——够做板块级对照，又不至于把其它板块挤小。

口径要讲清楚：**"差 ≤100"约束的是五个主板块；导数是按供给单列的专题板块，300 条，不参与该约束。**
若有人追问"为什么不拉到 740"，回答就是供给：要 740 道四选一导数题，需再采约 2 万道原始题。

## 第 7 页 · 评测指标

| 指标 | 定义 | 为什么需要 |
|---|---|---|
| 准确率 | 判对 / 参与评测 | 主指标 |
| 95% CI（Wilson） | 区间估计 | 4,000 题上 1 个点 ≈ 40 题，差 2 个点可能只是噪声 |
| 六板块宏平均 | 板块等权平均 | 防止 740 条的大板块压过 300 条的导数 |
| 未抽取率 | 没抽出 A–D | 指令遵循 |
| 失败率 | 请求层失败 | >5% 结果作废 |
| 板块×难度矩阵 | 6×3 格 | 看"在哪一档掉下去" |
| 测试方式 | 常规 / 深度思考 | 同一模型跑两遍，差值＝"多想一会儿"的净收益 |
| 耗时 / 调用次数 | 单题成本、平均调用轮数 | 深度思考的代价要一起报 |

两条下限参照：**随机猜 25.0%**、**全选 C 29.9%**（答案分布 A20.4 / B26.3 / C29.9 / D23.4）。
30% 以下等于没读题。

导数只有 300 条，它的准确率区间约 ±5.7 个百分点，报数时要带 n。

## 第 8 页 · 评测脚本

```
evaluate.py 一次运行 → results_<tag>.jsonl / summary_<tag>.json / summary_<tag>.md
                      / per_item_<tag>.csv / matrix_<tag>.csv
```

| 后端 | 场景 | 关键参数 |
|---|---|---|
| `openai` | OpenAI / DeepSeek / 通义 / 智谱 / vLLM / Ollama | `base_url` + `api_key_env` |
| `hf` | 本地 transformers | `model_path`、`device` |
| `llamacpp` | 本地 GGUF | `model_path`、`n_ctx` |
| `mock` | 无 Key 无显卡时验证链路 | `mock_accuracy` |

两种测试方式（提示词写死，换模式不换题）：

```bash
python evaluate.py --mode normal --tag ds-normal     # 常规：一次作答
python evaluate.py --mode deep   --deep-rounds 2 --tag ds-deep   # 深度：首答 + 复核
python compare.py --out results/leaderboard.md       # 两种方式并排出准确率
```

工程细节：并发可调、指数退避重试、`--resume` 续跑、`--dry-run` 只印 prompt、
按板块/难度/子集/来源/split 筛选、结果落盘即刷、逐轮答案记在 `stage_answers`。

## 附：可能被问到的

**Q：为什么导数只有 300 条，其它都是 740？**
A：供给决定。四选一导数题在题库里占 1.6%，且大量导数是填空/解答题；
可判分的导数池只有 614 道，取 300 单列。要拉到 740 需再采约 2 万道原始题。

**Q：那"各类型差 ≤100"还算达标吗？**
A：五个主板块完全达标（各 740，极差 0）。导数作为专题板块单列，不参与这条约束，
汇报时要主动说明这个口径，不要含糊过去。

**Q：4,000 条里为什么只有 147 条是 2019 年后的？**
A：菁优试卷带年份，但可判分题只有 200 多条；1010jiajiao 详情页不标年份。
`fresh` 子集只能看方向，不能下定量结论。

**Q：mock 的数字能写进汇报吗？**
A：不能当模型成绩。它的作用是证明"读数据 → 跑批 → 出表"链路是通的，
结果文件里 `meta.mock = true`，引用必须标注。
