# 数据集说明（v3 · 4,000 条）

> 本文件由 `make_dataset_doc.py` 从 `stats_v3.json` 生成，文中每个数字都能在统计文件里复查。

## 一、这是什么

高中数学四选一单项选择题集，共 **4000** 条，每条只有一个 A–D 答案，判分是字符串比对，不经过模型。
用途是给大模型做「解题能力」评测：同一批题、同一个 Prompt，比谁选对的更多。
题型、板块、难度都是可切的维度，答案与出处逐题保留，任何一条都能点回原页面核对。

### 交付格式

同一批题提供两份文件：

| 文件 | 说明 |
|---|---|
| `benchmark_v3.template.jsonl` | 按《高考题目数据集 JSON 收集规范 v1.0.0》输出，一行一题，主交付 |
| `benchmark_v3.jsonl` | 内部扁平格式，保留难度分值、content_hash、split 等构建期字段 |

模板格式的字段映射、校验结果与已知缺口见 `docs/数据格式说明.md`。

## 五、分布

### 5.0 主口径与细分

主口径 6 个板块用于配额与均衡；`sub_board` 保留十类细分（函数、三角、集合、导数等）。

| 细分板块 | 题量 |
|---|---|
| 函数 | 302 |
| 导数及其应用 | 300 |
| 数列 | 740 |
| 立体几何 | 740 |
| 解析几何 | 740 |
| 概率与统计 | 444 |

### 5.1 板块 × 难度

| 板块 | 基础 | 中档 | 压轴 | 合计 |
|---|---|---|---|---|
| 函数 | 296 | 296 | 148 | 740 |
| 导数及其应用 | 120 | 120 | 60 | 300 |
| 数列 | 296 | 296 | 148 | 740 |
| 立体几何 | 296 | 296 | 148 | 740 |
| 解析几何 | 296 | 296 | 148 | 740 |
| 概率与统计 | 296 | 296 | 148 | 740 |
| **合计** | **1600** | **1600** | **800** | **4000** |

- **板块配额**：除导数外的五个板块各 740–740 条，极差 0 条（要求 ≤100，达标）。
- **导数单列**：300 条（目标约 300）。四选一导数题供给有限（多为填空/解答题），因此按供给单列，不参与五板块的均衡约束。
- 五个主板块的配额由 maximin 分配得到：先把储量最小的板块装满，剩余名额在其它板块间均分；
  导数按固定目标单独取数，保证它作为一个独立板块有足够样本，又不至于把其它板块挤到 600 以下。
- 难度比例：基础 1600 / 中档 1600 / 压轴 800，严格 4:4:2。比例固定不是硬凑，而是「板块内按排名切」的必然结果：每个板块总有相对简单的四成。

### 5.2 年份

- 有年份的题共 167 条（4.2%）；2019 年及以后 **147** 条（3.7%），单独构成 `fresh` 子集。
- 年份主要来自菁优试卷标题；1010jiajiao 详情页不标年份，这部分记为「未知」。
- 老题公开十余年，无法排除训练语料覆盖；`fresh` 子集的作用就是做对照，而不是把老题删掉。

### 5.3 其他

- 带解析：2703 / 4000（67.6%）；菁优游客页不给解析，这是覆盖率下降的主要原因。
- 答案分布：A 816 / B 1053 / C 1194 / D 937；最高的是 C（29.8%）。四选项并不严格均衡，这是站点题库的既有偏差，评测时用「全选 C」作下限参照。
- 平均题干长度：56.2 字。
- 子集：core 3811 / extended 189；纯文本模型建议只跑 core。
- 划分：dev 200 条（调 Prompt）、test 其余；同一份数据固定随机种子，切分可复现。

## 六、怎么清洗的（六道闸）

1. **题型**：只留四选一；选项必须恰好四个且互不相同（含全角/半角标点归一后比较）。
2. **可判分**：答案必须是单个 A–D，且落在选项范围内；`AB`、`A、B`、`①②` 一律拦下。
3. **完整性**：题干 ≥ 8 字、无 `�` 编码损坏、图片 ≤ 4 张；纯图片题（去掉 `[图]` 后几乎无字）判为不可作答。
4. **学科纯净**：题干出现化学/物理术语（阿伏加德罗、电磁感应等）判为串科。
5. **板块可判**：六板块加权关键词投票（先按十类细分投票，再合并到六板块）。最高分 < 2、或最高 2 分却与次高并列，视为「证据不足」——
   这类题多是向量、复数、算法框图，或题干信号太弱无法归属，不在六板块内。
6. **去重**：题干归一化（去空白、去题号）后 md5 相同即重复；近重复要求 SimHash 汉明距离 ≤ 3 **且** 三元组 Jaccard ≥ 0.82，
   两个条件同时满足才删，避免把「同题干不同问法」误杀。

乱码修复：站点 GBK 混编会把 `△` 退化成 `D`、`∠` 退化成 `Ð`，入库前统一修回。

## 七、难度是怎么定的

规则分（0–8）= 板块先验（0–4）+ 题干长度档位 + 压轴关键词命中数 + 选项平均长度 + 是否配图 + 解析长度。
菁优来源另有难度星级 1–4，按 `2×星级−1` 折算后，以 0.35 权重与规则分加权（`difficulty_method = rule+stars`）。
**分档在板块内做**：每个板块按 `difficulty_score` 排序，前 40% 基础、次 40% 中档、末 20% 压轴。
这样六个板块都有三档（第二阶段几何板块没有基础题、矩阵留空），代价是不同板块的「基础」难度不完全等价——
跨板块比较请直接比 `difficulty_score`。连续分值保留，切点不喜欢可以自己重切。

**局限**：难度仍是规则初标，不是人工逐题标注。第三次汇报里配了 200 条 `review_sample.csv`，
用于抽检机器打分与人工判断的偏差；真正的 item-level 难度应等模型实测正确率出来后再校准。

## 八、已知偏差

1. **单板块偏重**：函数占近一半，总分容易被函数题主导，因此评测同时报「六板块宏平均」。
2. **来源不均**：jiajiao1010 占 96%，跨站去重后菁优剩余量有限；分来源指标只作参考，不作主结论。
3. **年份偏旧**：老题占比高，绝对分要打折看；`fresh` 子集是更接近真实能力的口径。
4. **解析不全**：菁优游客页不给解答，错因分析只能用 1010jiajiao 那部分。
5. **噪声**：站点原始录入错误（题干缺字、选项重复、答案笔误）无法完全排除；抽检 200 条可估个大概。

## 九、怎么用

- 评测：`eval/evaluate.py`，默认读 `data/benchmark_v3/benchmark_v3.jsonl`；
- 只跑纯文字题：`--subset core`；看污染影响：`--split test` 后按 `fresh` 子集单独统计；
- 引用时请注明：数据来源、构建日期、抽样种子（默认 42），以及是否使用 `fresh` 子集。
