# 数据格式说明（对齐《高考题目数据集 JSON 收集规范 v1.0.0》）

> 交付既保留内部扁平格式，也提供**按规范模板**的直接交付文件。
> 两者是同一批 4,000 条题，逐条一一对应（`extensions.internal_id` 可反查）。

---

## 一、交付文件

| 文件 | 格式 | 用途 |
|---|---|---|
| `benchmark_v3.template.jsonl` | 一行一题的 JSON | **主交付**，符合 v1.0.0 规范，可直接入库 |
| `benchmark_v3.template.json` | JSON 数组 | 一次性读入、给不熟悉 JSONL 的同学 |
| `benchmark_v3.jsonl` | 内部扁平格式 | 供构建脚本与统计复用，字段更紧凑 |
| `template_validation.json` | 校验汇总 | 尝试 / 有效 / 失败 / 跳过 计数 |
| `template_invalid.jsonl` | 隔离文件 | 校验失败记录（本次为空） |

生成与校验：

```bash
python crawler/export_template.py     # 扁平 → 模板
python crawler/validate_template.py   # 按规范逐条校验
```

## 二、字段映射

| 模板字段 | 取自 | 说明 |
|---|---|---|
| `schema_version` | 固定 | `1.0.0` |
| `id` | 来源原题 ID | `1010jiajiao-<shiti_id>` / `jyeoo-<uuid>`，不用题干哈希 |
| `question_type` | 固定 | `single_choice`（本数据集只收四选一） |
| `question` | `stem` | `^` 表幂次、`_` 表下标，`[图]` 表原题含图 |
| `choices` | `options` | `{"A": "...", "B": "..."}`，已去掉字母前缀 |
| `answers` | `answer` | 单元素数组，如 `["B"]` |
| `img_url` | 本地化主图 | 相对路径，如 `assets/images/xxxx.png`；无图为 `null` |
| `metadata.source.name` | `source` | 青夏教育精英家教网 / 菁优网 |
| `metadata.source.type` | 固定 | `website` |
| `metadata.source.url` | `source_url` | 逐题可点回原页 |
| `metadata.source.original_question_id` | 来源 ID | 与 `id` 后半段一致 |
| `metadata.source.collected_at` | `crawled_at` | 带时区 ISO 8601 |
| `metadata.exam.name` | `paper_title` | 仅在能关联到整卷时有值 |
| `metadata.exam.year` | `year` | 整数；未知为 `null` |
| `metadata.exam.exam_type` | 试卷名推断 | `gaokao` / `mock` / `practice`，推不出为 `null` |
| `metadata.exam.province/region` | `region` | 菁优试卷标题里的省份 |
| `metadata.exam.grade` | `grade` | 仅当为高一/高二/高三时填，否则 `null` |
| `metadata.exam.subject` | 固定 | `数学`；`education_stage` = `高中` |
| `metadata.position.section` | 固定 | `选择题`；原卷题号未采集，`question_number` 为 `null` |
| `metadata.content.knowledge_points` | `sub_board` | 细分板块（函数 / 导数及其应用 / …） |
| `metadata.content.difficulty` | `difficulty` | 基础→`easy`、中档→`medium`、压轴→`hard` |
| `metadata.content.difficulty_basis` | 生成 | 写明规则打分口径，避免把主观标签当统计结论 |
| `metadata.content.tags` | 生成 | 主板块、core/extended、采集路线 |
| `metadata.answer.explanation` | `analysis` | 无解析时为 `null` |
| `metadata.answer.answer_source` | 固定 | 「来源站点公开答案」 |
| `metadata.quality.status` | 规则 | 缺年份或试卷名 → `needs_review`，否则 `pending` |
| `metadata.quality.issues` | 生成 | 缺年份、缺试卷名、缺解析、含图、难度初标 |
| `metadata.provenance.transformations` | 生成 | 乱码修复、去选项前缀、去题号、空白归一 |
| `metadata.extensions` | 生成 | 主板块、难度分值、星级、content_hash、remote_images 等 |

## 三、校验结果

```
attempted 4000 / valid 4000 / failed 0 / skipped 0   pass_rate = 100%
```

校验项：`schema_version`、`id` 唯一性、`question_type` 合法性、题干非空且非纯图占位、
选择题 `choices ≥ 2`、`answers` 非空且都落在 `choices` 内、来源 URL 存在、
`img_url` 为安全相对路径、逐行标准 JSON。

隔离文件 `template_invalid.jsonl` 本次为空。

## 四、如实说明的缺口

1. **图片已本地化**：149 条题的 233 张图下载到 `assets/images/`，`img_url` 指向主图，
   `metadata.assets` 给出相对路径；另有 40 条源页无可用图（多为公式图），在 issues 标注「纯文本不可解」。
   子集口径改为「题干/选项含 `[图]` 或明确指向图/表」→ core **3,811** / extended **189**。
   规范要求资源用相对路径，我们没有下载图片，因此不伪造路径。
2. **试卷名与年份覆盖低**：`exam.year` 覆盖 4.2%（167 条），`exam.name` 覆盖 4.3%。
   1010jiajiao 详情页不标年份与卷名，只有菁优试卷能关联到整卷。
3. **质量状态**：`needs_review` 3,833 条、`pending` 167 条——因为没有人工逐条复核，
   按规范第 2 条，缺关键信息的一律标 `needs_review`，不冒充已核验。
4. **难度**：`easy/medium/hard` 是规则初标 + 板块内排名切档，`difficulty_basis` 里写明了口径；
   人工复标清单见 `review_sample.csv`。

## 五、与内部格式的差异（为什么保留两份）

内部扁平格式带 `difficulty_score`、`content_hash`、`split` 等构建期字段，
方便重切阈值和复现抽样；模板格式面向交付与入库，字段更规范但冗余。
两份数据由 `extensions.internal_id` 一一对应，改动任一份都应重新导出，避免漂移。
